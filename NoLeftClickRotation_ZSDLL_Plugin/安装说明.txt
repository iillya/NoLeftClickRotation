NoLeftClickRotation（禁用左键视图旋转）安装说明 —— ZScript + DLL 版
================================================================

适用版本：ZBrush 2026（官方 ZPlugin 格式，纯 Win32，无 Python）。

插件格式
--------
官方 ZPlugin：.zsc（界面 + 画布状态检测）+ DLL（输入拦截）。
无安装程序、无环境变量、不写开机启动项，随 ZBrush 启动/退出。

功能
----
在 ZBrush 雕刻（Edit 模式）下，禁用“左键按住空白画布拖动触发视图旋转”。
- 空白画布：无修饰键左键（旋转）与 Alt+左键（平移）均被禁用；
- 模型上：原样雕刻，笔刷不会被中途掐断；
- 光标从空白处拖到模型上时，笔刷从进入点正常起笔；
- Ctrl+左键（框选遮罩）保留，界面滑块/按钮/画布内自定义 UI 正常；
- 判定使用官方 PixolPick 材质索引（0 = 空白画布），不比较颜色。

工作原理
--------
1. .zsc 的 [Sleep] 事件循环（掩码 15 = 定时器|鼠标移动|左键按下|抬起）
   实时检测画布状态：MouseHPos/VPos + IGet Transform:Edit + PixolPick，
   移动 >=4px 或按键事件时通过 [FileExecute] 推送给 DLL（UpdateState）；
2. DLL 把 ZBrush.exe 导入表的 GetAsyncKeyState 指向机器码存根：
   空白画布（且未按 Ctrl）时对 VK_LBUTTON 返回 0，旋转/平移无从触发；
   模型上返回真实状态，雕刻不受影响；DLL 同时子类化窗口处理起笔/收笔。

安装
----
1. 完全关闭 ZBrush；
2. 把 NoLeftClickRotation.zscript.txt 编译为 .zsc（二选一）：

   方式 A（ZScript 面板，用户手动操作）：
     启动 ZBrush → ZScript 面板 → Load 选择 NoLeftClickRotation.zscript.txt
     → 脚本编译并运行 → 用面板 Save 保存为 .zsc；

   方式 B（DefaultZScript 法，旧版官方插件文档化方法）：
     备份 ZData\ZScripts\DefaultZScript.txt 与 DefaultZScript.zsc；
     用 NoLeftClickRotation.zscript.txt 覆盖 DefaultZScript.txt，
     删除 DefaultZScript.zsc；启动一次 ZBrush 等待生成新的
     DefaultZScript.zsc 后退出；将其复制为 NoLeftClickRotation.zsc；
     恢复备份的 DefaultZScript.txt / .zsc。

3. 把 .zsc 与 NoLeftClickRotationData 文件夹复制到：
   C:\Users\[用户名]\AppData\Roaming\Maxon\Maxon ZBrush 2026_*\ZStartup\ZPlugs64\
   最终结构：
   ...\ZPlugs64\NoLeftClickRotation.zsc
   ...\ZPlugs64\NoLeftClickRotationData\NoLeftClickRotation.dll
4. 重启 ZBrush；Z插件 菜单 → 禁用左键视图旋转 → 启用（默认已启用）。

首次运行会在 NoLeftClickRotationData 下自动生成 config.txt（1=启用）。

卸载
----
关闭 ZBrush，删除 ZPlugs64 下的 NoLeftClickRotation.zsc 和
NoLeftClickRotationData 文件夹即可。不修改 ZBrush 安装目录
（DefaultZScript 法临时改动会在完成后恢复），不写注册表/环境变量。

说明
----
- ZBrush 同一时间只运行一个 ZScript：被其他插件/宏打断时，检测循环暂停，
  DLL 按最近一次推送的状态降级（空白=屏蔽、模型=放行），无需手动校准；
- 插件不修改视图变换、不产生画布残影；如遇画布残留，Ctrl+N 清空画布。
