# 禁用左键导航（No Left Click Rotation）

适用于 Windows 版 ZBrush 2026 的 Python 插件。它会在 Edit 模式下锁定相机，避免从空白画布开始拖动左键时旋转视角，同时尽量保留 ZBrush 的原生界面、LightBox 与雕刻操作。

> 提示：这是一个会处理鼠标输入的插件。若使用过程中左键出现异常行为，请立即关闭「启用」开关，并重启 ZBrush。

## 功能

- 在 Edit 模式下自动锁定相机，阻止左键拖动空白画布时旋转视角。
- 右键按下时临时解除相机锁定，松开后自动重新锁定，便于正常旋转视角。
- 左键位于模型上时，保持正常雕刻行为。
- 左键从空白画布拖入模型后，会尝试衔接为正常雕刻起笔。
- ZBrush 原生 UI（按钮、菜单、滑条、面板）上的左键操作会完整放行。
- Ctrl + 左键保留 ZBrush 原生画布手势；Alt + 左键使用与普通左键相同的区域判定。
- 插件仅在首次进入 Edit 模式后安装输入钩子，避免干扰 ZBrush 启动和 LightBox 初始化阶段。

## 安装

1. 完全退出 ZBrush。
2. 将 `NoLeftClickRotation.py` 复制到当前用户的插件目录：

   ```text
   %APPDATA%\Maxon\Maxon ZBrush 2026_*\ZStartup\ZPlugs64\
   ```

3. 启动 ZBrush。
4. 打开 `Zplugin > 禁用左键导航`，确认「启用」处于开启状态。
5. 进入 Edit 模式后，插件才会安装输入处理逻辑并开始生效。

## 使用方式

### 左键

| 位置或操作 | 插件行为 |
| --- | --- |
| ZBrush UI，例如按钮、滑条、菜单和面板 | 完整交给 ZBrush 处理。 |
| 模型表面 | 正常雕刻。 |
| 空白画布 | 不触发左键视角旋转。 |
| 从空白画布拖入模型 | 尝试切换为正常雕刻起笔。 |
| Ctrl + 左键 | 保留 ZBrush 原生手势。 |

### 右键

在 Edit 模式中，右键按下会临时解除相机锁定；松开右键后，插件会自动重新锁定相机。

## 面板

- **启用**：插件总开关。关闭后插件解除相机锁定，并停止处理左键。
- **哔哩哔哩**：打开作者主页。
- **GitHub**：打开项目主页。

## 兼容性与安全机制

- 输入钩子只会在 Edit 模式开启后安装。
- 如果游标监视、窗口消息钩子或轮询定时器无法安装，插件会自动清理已安装部分、解除相机锁定、禁用「启用」按钮，并显示「禁用左键导航插件不可用」。两个跳转链接仍可使用。
- 当插件内部出现异常时，也会进入相同的安全停用流程，避免继续干扰 ZBrush 输入。
- 拖动 ZBrush 原生 UI 时，插件会暂停相机锁定写入和画布查询，避免干扰滑条等控件的实时刷新。

## 已知限制

- LightBox 资源尚未刷新完成时，请等待缩略图和光标稳定后，再双击打开工程；这是为了避免 ZBrush 初始化过程与鼠标处理同时发生冲突。
- 画布和界面区域判定依赖 `Preferences:Utilities:View Window Id`。若该接口不可用，左键画布过滤能力会受限。
- 从空白画布拖入模型的起笔依赖 ZBrush 的 `PixolPick` 结果；极少数特殊笔刷或非编辑状态下可能无法衔接。
- 该插件使用 Windows 专用的鼠标与窗口机制，仅支持 Windows 版 ZBrush。

## 卸载

1. 完全退出 ZBrush。
2. 删除以下文件：

   ```text
   ZStartup\ZPlugs64\NoLeftClickRotation.py
   ```

3. 重新启动 ZBrush。
