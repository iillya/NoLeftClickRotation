# 禁用左键导航（No Left Click Rotation）

适用于 Windows 版 ZBrush 2026 的 Python 插件。插件会在 Edit 模式下锁定相机，阻止左键从空白画布开始拖动时旋转视角，同时保留正常的 UI 操作、模型雕刻和右键旋转。

> 如果使用过程中发现左键出现异常行为，请立即关闭「启用」开关，并重启 ZBrush。

## 主要功能

- Edit 模式下自动锁定相机，避免左键拖动空白画布时旋转视角。
- 右键按下时临时解除相机锁定，松开后自动重新锁定。
- 模型表面的左键操作保持正常雕刻。
- 左键从空白画布拖入模型后，自动衔接为雕刻起笔。
- 按钮、菜单、滑条和面板等 ZBrush 原生 UI 操作完整放行。
- Ctrl + 左键保留 ZBrush 原生手势；Alt + 左键沿用普通左键的区域判断。
- 插件仅在首次进入 Edit 模式后安装输入钩子，避免干扰启动和 LightBox 初始化。
- 不模拟中键，不修改模型数据。

## 安装

1. 完全退出 ZBrush。
2. 将 `NoLeftClickRotation.py` 复制到当前用户的插件目录：

   ```text
   %APPDATA%\Maxon\Maxon ZBrush 2026_*\ZStartup\ZPlugs64\
   ```

3. 重新启动 ZBrush。
4. 打开 `Zplugin > 禁用左键导航`，确认「启用」处于开启状态。
5. 进入 Edit 模式后，插件开始生效。

## 操作逻辑

### 左键

| 操作位置 | 处理方式 |
| --- | --- |
| ZBrush UI、LightBox | 原样交给 ZBrush。 |
| 模型表面 | 正常雕刻。 |
| 空白画布 | 经过 5ms 分类后结束左键画布操作，阻止视角旋转。 |
| 从空白画布拖入模型 | 补发左键按下和移动，衔接为雕刻起笔。 |
| Ctrl + 左键 | 保留 ZBrush 原生手势。 |

空白画布处理只会模拟必要的左键松开、按下和移动，不会发送任何模拟中键消息。

### 右键

在 Edit 模式中，右键按下会临时解除相机锁定；右键松开后，插件会自动重新锁定相机。

## 插件面板

- **启用**：插件总开关。关闭后停止左键处理并解除相机锁定。
- **哔哩哔哩**：打开作者的哔哩哔哩主页。
- **GitHub**：打开项目主页。

## 安全机制

- 启动和 LightBox 初始化阶段不安装输入钩子；插件每 100ms 检查一次 Edit 状态，首次进入 Edit 模式后才安装。
- 游标监视、窗口消息钩子或输入轮询安装失败时，插件会清理已安装部分、解除相机锁定并禁用「启用」按钮。
- 输入回调发生异常时，插件会执行相同的安全停用流程，并显示「禁用左键导航插件不可用」。
- 左键按住期间暂停相机锁定写入和画布预取，避免干扰 ZBrush 滑条与动态 UI。
- 两个跳转链接不受输入钩子失败影响。

## 工作原理

插件通过 ZBrush Python API 查询 Edit 状态、画布位置和模型材质信息；通过 Windows 窗口子类接收鼠标消息，并监视 `SetCursor` 调用来区分原生 UI 与画布。空白画布分类延迟为 5ms，拖入模型后的补发起笔延迟为 1ms。

## 已知限制

- 仅支持 Windows 版 ZBrush 2026；其他版本需要单独验证兼容性。
- 画布区域判断依赖 `Preferences:Utilities:View Window Id`。该接口不可用时，左键画布过滤能力会受限。
- 拖入模型的起笔判断依赖 `PixolPick`；特殊笔刷、非 Edit 模式或特殊画布状态下可能无法衔接。
- LightBox 仍在加载资源时，建议等待缩略图和光标稳定后再打开工程。
- ZBrush 自动显示的 Python 动态 UI 快捷键尾缀属于软件自身行为，官方 Python API 暂不提供隐藏接口。

## 卸载

1. 完全退出 ZBrush。
2. 删除：

   ```text
   ZStartup\ZPlugs64\NoLeftClickRotation.py
   ```

3. 重新启动 ZBrush。
